# Thai grammar sequence (curated — see ATTRIBUTION.md)

One point per lesson, in order, starting at L9 (after the Unit 0 script bootstrap).
Stages map to the level track: A ≈ tier1 words, B ≈ tier2, C ≈ tier3, D ≈ tier4+.

## Stage A — survival core
1. SVO word order; no conjugation, no plurals, no articles — words never change form
2. Polite particles ครับ (male speaker) / ค่ะ, คะ (female speaker); when they attach
3. Personal pronouns ผม / ฉัน / คุณ; dropping pronouns when context is clear
4. Negation with ไม่ before the verb
5. Yes–no questions with ไหม; answering by echoing the verb (no word for yes/no)
6. อะไร "what"; question words stay in sentence position (no fronting)
7. Adjectives are verbs: no copula with adjectives; เป็น/คือ only noun=noun
8. มี "to have / there is"
9. Possession and "of" with ของ (and when it drops)
10. อยาก + verb "want to"; เอา for wanting things
11. ที่ไหน "where"; location with ที่ / ใน / บน
12. Future/intent with จะ
13. Completed action with แล้ว
14. Progressive with กำลัง (+อยู่)
15. ได้ after the verb: can / get to; ไม่ได้ before verb: didn't
16. Numbers 1–100; กี่ + classifier for "how many"; เท่าไหร่ "how much"
17. Classifiers: the คน/อัน system — noun + number + classifier order
18. Requests: ขอ + noun, ช่วย + verb + หน่อย; softening particles

## Stage B — connected speech
19. ใคร "who"; ทำไม "why"; เพราะ(ว่า) "because"
20. หรือ "or"; ...หรือเปล่า / ...ใช่ไหม tag questions
21. เคย experiential "have ever"; ไม่เคย "never"
22. ต้อง "must"; ควร "should"; อาจ(จะ) "might"
23. Comparison with กว่า; superlative ที่สุด
24. Relative clauses with ที่
25. ว่า complementizer after say/think/know
26. ถ้า "if" conditionals; ก็ in the result clause
27. Time expressions: days, months, telling time (โมง system), เมื่อไหร่ "when"
28. ให้: give, for, causative "have someone do"
29. Verb serialization: ไป/มา direction, เอา...ไป/มา carrying
30. กำลังจะ about-to; เพิ่ง "just did"; ยัง "still / not yet"

## Stage C — workplace register
31. Formal pronouns and titles: คุณ + name, ท่าน; kinship terms as pronouns (พี่/น้อง) in offices
32. น่า + verb "worth -ing / -able"; น่าจะ "probably should"
33. ถูก/โดน passive (and why Thai avoids it); topicalization instead
34. ทำให้ causation; เพื่อ "in order to"
35. Politeness architecture: กรุณา / โปรด, indirectness, softeners นะ / หน่อย / ครับผม
36. Reported speech and opinion: คิดว่า / บอกว่า / เห็นว่า
37. แบบ / อย่าง / เหมือน comparison and "kind of"
38. Numbers large (พัน/หมื่น/แสน/ล้าน), prices, percentages — meeting-room arithmetic
39. ทั้ง...และ / ไม่...ทั้งนั้น scope; ต่าง "each/various"
40. Connectors for argument: อย่างไรก็ตาม, ดังนั้น, นอกจากนี้ (formal register)

## Stage D — business proficiency
41+. Formal/written register vs spoken; email frames; meeting facilitation phrases; negotiation
hedging; royal/sacred register awareness (recognition only). Sequenced ad hoc from tier3–4
vocabulary and real scenario needs; each point still one per lesson, guided-discovery format.

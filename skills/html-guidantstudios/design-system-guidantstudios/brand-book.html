    08 / what this style is not
    
the drift list

    

      
fonts
  • Outfit, Inter, Roboto, Helvetica, Poppins, Montserrat, Space Grotesk, Syne, Unbounded
  • any serif or script
  • Courier / Fira / Space Mono - mono is JetBrains only
  • Archivo widths other than 100/125; weights 100-300, 900
  • Doto for body, labels, buttons, nav
  • figlet banner headlines; uppercase normal-width heads

      
colours
  • a second blue - navy, sky, cyan, teal, neon
  • purple or blue-to-purple "AI" gradients
  • robo orange/cream, dsx silver accent
  • red/green status fills, rainbow charts
  • gradients except foil, metal-fx, hard-stop patterns
  • pure #000 backgrounds, pure #fff text on dark

      
effects
  • blurred or glowing shadows, neon outlines
  • glassmorphism, backdrop blur
  • pills, radii above 4px
  • ASCII + metal in one section; metal text or buttons
  • matrix-green rain, scanlines, RGB glitch
  • dotted or halftone agents; ring/orbit shape
  • more than one animated effect per page
  • stock photos, 3D clay, emoji icons, icon fonts

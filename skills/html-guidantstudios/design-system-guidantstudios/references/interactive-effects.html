Five interactive DOT effects

Same family as the particle typography: everything is dots in paper, black and cobalt, and everything answers the mouse. Move your cursor through each stage. All five are part of the skill - copy the matching IIFE block straight from this file.

01

Torch reveal

Use it for: a hero that starts almost empty - a shaded dot-matrix subject only materialises where the cursor sweeps, and slowly fades again behind you. Great for "explore this" landing moments and product teasers.

sweep the dark · lambert-shaded sphere + hex
02

Flow field

Use it for: an ambient background with real physics - dot-dust drifting along an invisible current. The cursor stirs the field like a hand in water. Calmer than the text effect, so it can sit behind content.

stir it · ink dust, cobalt strays
03

Agent constellation

Use it for: the network metaphor - agents, community, systems talking to each other. Nodes drift quietly; near your cursor they link up with lines and the closest ones go cobalt. Perfect for community and multi-agent slides.

hover to connect · nodes + links
04

Elastic grid

Use it for: a disciplined, architectural texture that turns out to be alive - a perfect halftone grid that bows away from the cursor and springs back. Click for a shockwave. Works behind section headers where the wilder effects would be too loud.

push it · click = shockwave
05

Shape morph

Use it for: storytelling transitions - the same particles reform from the studio hex into a bar chart into an arrow. Same spring-and-fling physics as the text engine, so the mouse still scatters them mid-morph. Click to jump to the next shape.

click to morph · hex → chart → arrow → nugget
